## 背景

内部管理系统、营销活动页、数据看板、移动端 H5 等页面重复开发成本高。目标是建设统一低代码平台，让业务方通过可视化搭建快速交付页面。

## 我做了什么

- 搭建 React 版平台前端，基于 Next.js 实现服务端渲染与客户端渲染混合模式，优化首屏加载与 SEO。
- 实现可视化搭建编辑器：组件拖拽、属性配置、样式调整、页面预览与发布；基于 WebSocket 支持多人协作编辑与实时同步，内置撤销重做、模板保存与版本管理。
- 设计组件注册与渲染服务层（`useComponentService`），用泛型与策略模式统一不同组件库的注册、属性绑定与事件处理，结合 React Query 做组件资源按需加载。
- 针对大型页面组件树与拖拽编排场景引入虚拟渲染与增量更新，在千级组件数量下保持 60fps。
- 封装组件选择器、属性配置面板、页面结构树、主题设置器等编辑器组件。
- 实现页面数据源与状态管理：API 数据绑定、静态数据配置、跨组件通信、条件渲染，通过响应式数据流与依赖追踪平衡灵活性与运行时性能。
- 构建管理端：组件统一管理、权限配置、资源统计、异常监控，基于 ECharts 做多维看板。
- 基于 Docker + GitHub Actions 标准化部署，维护接入文档与最佳实践。

## 结果

多个业务场景可以通过搭建快速交付页面，重复开发明显减少，组件资源集中管理与复用。
