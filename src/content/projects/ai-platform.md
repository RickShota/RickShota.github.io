## 背景

公司内部多条业务线各自接入大模型，能力重复建设、技术栈不统一。项目目标是建设统一的 AI 能力中台，为智能办公、代码生成、数据分析、智能客服等场景提供一致、稳定、可扩展的接入方案。

## 我做了什么

- 从零设计并实现中台前端的 Chat 会话界面，支持多模型对话、会话管理与历史回溯；基于 SSE 实现消息流式输出与实时渲染，集成 Markdown 解析、代码高亮与公式渲染。
- 设计统一的 AI 服务调用层（`useAIService`），用 TypeScript 泛型与策略模式封装多模型切换、参数动态配置与错误统一处理，统一对话、文生图、Embedding 等能力的调用接口。
- 针对对话历史与会话列表等长列表场景引入虚拟滚动，通过动态渲染与 DOM 回收，在万级数据量下保持流畅滚动。
- 封装模型选择器、API 状态监控、Token 实时统计等通用组件，用泛型约束组件的输入输出类型。
- 实现多轮对话上下文管理：上下文长度可配置、记忆窗口滑动、关键信息持久化，通过智能裁剪与压缩控制 Token 消耗。
- 构建管理端应用，实现模型统一配置、权限管理、用量统计与异常监控，基于 ECharts 输出多维数据看板。
- 推动 Docker 容器化与 CI/CD 标准化，实现多环境一致部署，并维护接入文档与组件 API 文档。

## 结果

一套中台支撑多个业务场景的 AI 能力接入，前端侧沉淀出可复用的服务层与组件库，业务接入成本明显降低。
