## 背景

原系统基于 Vue2 + Options API 构建，代码组织混乱、TypeScript 支持不完整、性能瓶颈明显。目标是在业务不停摆的前提下完成 Vue3 迁移，并引入 AI 智能分析能力，把系统从操作型工具升级为分析决策平台。

## 我做了什么

- 主导 Vue2 → Vue3 迁移，用 Composition API 重写全部业务组件，建立严格的 TypeScript 类型体系，系统性清理原系统中的隐式类型问题。
- 设计 AI 智能分析报告：用户用自然语言提问（如「分析上月 A 类物料的库存周转情况」），系统生成包含可视化图表、关键洞察与优化建议的完整报告。
- 构建混合实时通信架构：审批状态、库存预警等轻量通知走 SSE；大屏监控与多人协同走 WebSocket，并做连接池管理与断线重连，适配工业网络环境。
- 基于 ECharts 封装智能图表组件，根据查询意图推荐图表类型（时序趋势用折线、占比分析用饼图），自动优化配色与数据标签。
- 实现物料异常检测与根因分析：结合时序异常检测与大模型生成可能原因、影响范围与处理建议，支持一键生成标准工单。
- 设计渐进式数据加载策略：首屏关键数据优先、非关键数据按需、高频查询本地缓存、复杂分析后台执行。
- 针对工业 PAD 优化触摸交互，用 Service Worker 缓存核心业务逻辑，弱网下仍可完成出入库与盘点。

## 结果

系统完成技术栈与架构的彻底重构，AI 分析能力让固定报表变成可交互的智能报告，老系统的性能与可维护性问题得到系统性解决。
